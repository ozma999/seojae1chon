# 초대 안내문

`<앱 주소>`만 실제 주소(예: https://seojaemate.vercel.app)로 바꿔 쓴다. 최초 가족 코드는 **FAMILY**(10명, 기한 없음).

## 슬랙용

```
:books: *서재일촌 최초 가족을 모집해요* (선착순 10명)

가진 책을 등록하면 *픽셀 서재*가 채워지고, 책이 늘수록 방이 넓어져요. 친구 서재에 놀러 갈 수도 있어요.
여러분이 *최초 가족*이 되어 주세요. :house_with_garden:

:point_right: <앱 주소>
:key: 초대 코드 `FAMILY`

*시작하기*
1. 링크를 열고 *초대 코드로 시작하기*
2. 이메일·비밀번호·초대 코드로 가입 → 빈 방이 생겨요
3. *책 추가* 탭에서 책 뒷면 바코드를 찍어 보세요 (제일 빨라요)

*비밀번호*: 8자 이상, 영문 대문자·소문자·숫자·기호(!@# 등)를 모두 넣어 주세요. 다른 사이트에서 안 쓰는 새 비밀번호로요.

*책 빨리 넣기*
• *연속 바코드*: 책을 쌓아 두고 차례로 찍으면 목록에 쌓였다가 한 번에 꽂혀요
• *텍스트 붙여넣기*: 책장 사진의 글자를 복사해 붙여 넣으면 한꺼번에 찾아 줘요
  ◦ 아이폰: 사진 앱에서 글자 길게 누르기 → 모두 선택 → 복사
  ◦ 안드로이드: 구글 렌즈 → 텍스트 → 모두 선택 → 복사
• *시리즈*(만화 등): 한 권 고르면 *이 권만 / 전체 / 일부 고르기*

*더 해 볼 것*
• 책을 눌러 *자랑 책장에 꽂기* → 그 책 장르로 방 테마가 바뀌어요
• *일촌* 탭 → *서재산책*으로 서로의 서재 구경, *공유 카드*로 내 서재 자랑
• 앱처럼 쓰기: 아이폰 사파리 공유 → *홈 화면에 추가* / 안드로이드 크롬 ⋮ → *홈 화면에 추가*

:gift: *최초 가족 혜택*: 책장 사진 한 장으로 여러 권을 한 번에 등록하는 기능을 가장 먼저 열어 드릴 예정이에요.

:warning: 테스트 중이라 가끔 고장 날 수 있어요. 이상하면 화면 캡처와 함께 이 스레드에 남겨 주세요.
비밀번호 재설정 메일은 *요청한 그 휴대폰*에서 열어야 돼요.

일주일쯤 써 보고 :thread: 스레드에 느낌을 남겨 주시면 큰 힘이 돼요 :pray:
```

## 슬랙 피드백 요청(3~7일 뒤, 같은 스레드에)

```
:speech_balloon: *서재일촌 최초 가족 피드백* — 편한 것만 답해 주세요!
1. 책을 몇 권쯤 넣었나요? 제일 편했던 방법은? (바코드 / 연속 / 붙여넣기 / 검색)
2. 못 찾은 책이나 엉뚱하게 나온 책이 있었나요? (제목 알려 주시면 고칠게요)
3. 서재 그림을 보고 어떤 느낌이었나요? 더 있었으면 하는 건?
4. 서재산책(친구 서재 구경)은 해 봤나요?
5. 공유 카드를 누구에게 보내고 싶었나요? 안 보냈다면 왜?
6. 제일 불편했던 점 하나, 제일 좋았던 점 하나
:arrow_right: 이모지로만 답해도 좋아요: :heart: 재밌다 / :thinking_face: 애매하다 / :hammer_and_wrench: 고칠 게 많다
```
