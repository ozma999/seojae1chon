# 서재일촌 인수인계서

작성일: 2026-11-21 · 기준 문서: `pixel-library-plan.html` (기획서 v0.6)

새 대화를 시작할 때 이 문서와 아래 파일들을 함께 첨부하고, 맨 아래 '시작 프롬프트'를 붙여 넣으면 됩니다.

---

## 1. 프로젝트 한 줄 요약

**서재일촌**: 내가 가진 책을 등록하면 픽셀아트 서재(싸이월드 미니홈피 감성)가 채워지고, 책으로 서재와 아바타를 꾸며 공유 카드로 자랑하는 책 아카이빙 앱/웹. 기획자는 현우(개인 프로젝트). 첫 사용자는 지인 소수(초대 코드).

**메인 콘텐츠 순환**
1. 책 등록(바코드, 책장 사진 일괄 인식, 검색)
2. 권수 기준을 넘으면 서재 아이템과 아바타 머리·옷이 열림
3. 아이템 켜고 끄기, 아바타 갈아입히기, 자랑 책장에 대표 책 꽂기
4. 공유 카드로 자랑
5. 친구가 '서재산책'으로 들어와 자기 방을 만듦

## 2. 받은 파일과 역할

| 파일 | 역할 |
|---|---|
| `pixel-library-plan.html` | 기획서 v0.6 + 클릭 프로토타입. 이미지와 아트 데이터가 전부 내장된 단일 파일(약 1.2MB) |
| `seojae-art-src/lib.py` | 렌더러 핵심. 32색 팔레트 `PAL32`, `Scene` 클래스(방 외곽, 원근 책장, 책등, 표지, 옆벽 원근 책장·창). `Scene(theme=...)`로 벽·바닥·천장 무늬와 그림자 색을 바꿈(기본 `ATTIC` = 기존 방과 픽셀 단위 동일) |
| `seojae-art-src/sprite.py` | 초기 캐릭터 문자열 맵 `CHAR` (lib.py가 import하므로 필요) |
| `seojae-art-src/scenes.py` | Lv.1~4 방 장면 함수(`lv1`~`lv4`)와 창·화분·스탠드·러그 등 소품 함수 |
| `seojae-art-src/rooms.py` | **최신.** '빈 방 + 아이템 레이어 + 테마' 구조. 테마표 `THEMES`, 입체 가구, Lv.4 천장 레일 사다리, 아이템 해금표 `ITEMS`, 레벨별 배치 `L1`~`L4`(물건 하나당 레이어 하나), 창 유리 자리 표시(`win`, `side_win`), 수용량 계산 `capacity()`, 내보내기 `export()` |
| `seojae-art-src/avatar9.py` | **확정 아바타(v7 기반).** 헤어 8종 × 옷 8종 종이 인형 구조, 후드 A안 |
| `seojae-art-src/windows.py` | 창밖 풍경 16장소 × 새벽·낮·노을·밤. `render(scene, tod, w, h, pal, skypal)`로 창 크기에 맞춰 그림(40×32는 기존과 동일). import해도 시트를 만들지 않음 |
| `seojae-art-src/materials.py` | 벽·바닥 재질 64종 썸네일. 무늬 함수(`panel`, `dots`, `check`, `carpet` 등)를 `rooms.py`가 테마에 씀 |
| `seojae-art-src/export_art.py` | 아바타 스프라이트 시트 + (구버전) 레벨 배경을 `art.json`으로 내보냄 |
| `seojae-art-src/fonts.py` | OS별 한글 폰트 찾기, 썸네일 출력 폴더(기본 `./out`) |
| `seojae-art-src/art.json`, `art2.json` | 현재 아트 데이터. `art2.json`이 HTML에 들어간 최종본 |
| `seojae-art-src/README.md`, `requirements.txt` | 실행 순서, 필요한 패키지(Pillow) |

**13개 파일을 모두 한 폴더(`seojae-art-src`)에 넣어야 합니다.** 서로 import하는 구조라 하나라도 빠지면 실행되지 않습니다. 빈 환경에서 처음부터 실행되는 것을 확인했습니다.

### 아트 파이프라인 (Python 3 + Pillow)
```
pip install Pillow
cd seojae-art-src
python3 rooms.py           # art2.json 생성 (art.json이 없으면 export_art.py를 자동 실행)
python3 avatar9.py         # out/ 에 아바타 시트
python3 windows.py         # out/window-views-64.png
python3 materials.py       # out/materials-64.png
```
- `art2.json`의 내용이 HTML 안의 `const ART={...};` 한 줄에 들어갑니다. 그림을 바꾸면 이 JSON만 교체하면 됩니다.
- `art2.json` 레벨 구조: `bg`(테마별 빈 방), `win`(창마다 위치와 테마×시간대 풍경 조각), `items`(물건별 레이어), `lights`(조명 범위), `slots`, `brag`, `foot`, `sidecap`, `cap`(수용량). 최상위에 `themes`, `tods`, `pal`(PAL32), `itemdefs`, `avatar`.
- 창 유리는 렌더 중 표시색(255,0,255)으로 비워 두고, 그 픽셀만 남긴 풍경 조각을 따로 내보냅니다. 프로토타입은 책을 꽂은 **뒤에** 창 조각을 얹습니다(풍경 색이 책장 뒷판 색과 같아도 책이 그려지지 않게).
- 책은 그림에 굽지 않습니다. 배경에는 빈 책장만 있고, 프로토타입이 칸 좌표(`slots`)에 실제 책 데이터를 꽂습니다. 책은 배경의 책장 뒷판 색(70,44,32) 픽셀 위에만 그려지므로 사다리·계단이 책 앞에 남습니다.
- 아이템 레이어는 같은 장면을 표시색으로 덮은 뒤 물건 하나만 그려서 뽑습니다(배경과 같은 색 픽셀도 빠지지 않음). 레이어는 물건 하나당 하나이고(같은 id가 여러 개일 수 있음), `kind`(wall/floor)와 `base`(바닥 기준 y)를 가집니다. 바닥 물건은 캐릭터 발 위치와 비교해 앞뒤가 정해집니다.
- 썸네일 시트의 한글 라벨 폰트는 `fonts.py`가 리눅스(Noto CJK), 맥(애플 SD 산돌고딕 Neo), 윈도(맑은 고딕) 순으로 찾습니다.

## 3. 확정된 결정

### 이름과 어휘
- 앱 이름: **서재일촌** (확정, '일촌' 유지). 공개 검색으로는 '일촌' 등록상표도, '서재일촌' 같은 서비스도 찾지 못함(KIPRIS 직접 조회는 이 환경에서 막혀 미확인). 싸이월드가 2026년 11월 말 재오픈하면서 일촌·일촌평을 다시 내세우고 있어, 상표 등록과 별개로 부정경쟁방지법(널리 알려진 표지) 쪽 위험은 남음. 출시 전 KIPRIS에서 '일촌', '1촌', 'ILCHON', '서재일촌'을 9·35·38·41·42·45류로 확인할 것.
- 어휘: 파도타기 → **서재산책**, 투데이 → 오늘 방문, 일촌평 → 서재평, 미니미 → 책미니. 싸이월드 고유 용어(미니홈피, 미니미, 도토리 등)는 그대로 쓰지 않음.

### 방 아트
- 이미지 생성 도구(Canva, 나노바나나)는 **기각**: 무난하고 AI 느낌, 양산형. **코드로 픽셀을 직접 찍는 방식**으로 확정.
- 정면 하이앵글 무대형, 소실점 하나. **모든 단계 4:3**. **방 전체 32색 팔레트**(`lib.PAL32`), 1px 진한 외곽선, 그라데이션·빛 번짐 없음.
- 레벨: Lv.1 클로즈업 288×216 / Lv.2 방 384×288 / Lv.3 큰 서재 512×384 / Lv.4 복층 서재 768×576. 캐릭터 크기는 고정, 방이 커지며 화면에서 작아짐.
- 수용량(데모 책 기준 실측, `rooms.py`가 출력): Lv.1 약 100권, Lv.2 약 290권, Lv.3 약 920권, Lv.4 약 2,100권. 책장이 차면 다음 단계로 넓어짐. 2,100권 초과분은 보관함(방 추가는 v1).
- 입체감: 책장 측판·바닥 받침·벽 그림자, 가구 윗면·옆면·바닥 그림자, 옆벽 원근 책장, 기둥·몰딩. **커튼은 창 위 짧은 커튼**(책장 뒤로 들어가면 안 됨).
- 대표 책 테마 4종 연결 완료(v0.6): 다락방(문학·기본, 바다), 우주정거장(SF·판타지, 우주), 만화방(만화, 도시), 서고(인문·과학, 숲). 벽·옆벽·바닥·천장·걸레받이·책장 그림자 색과 창밖 풍경이 바뀜.  나머지 풍경 12종과 재질 60종은 v1 테마 확장용.
- **방의 시간 = 휴대폰 시각.** 창밖 풍경과 방 조명이 새벽·낮·노을·밤으로 바뀜. 경계는 그날의 해 뜨고 지는 시각(서울 기준, 날짜로 계산, 위치 권한 불필요): 새벽 = 해 뜨기 1시간 전~뜬 뒤 30분, 낮 = ~해 지기 45분 전, 노을 = ~해 진 뒤 30분, 밤 = 그 밖. 1분마다와 앱 복귀 시 확인.
- 밤 밝기(v0.7): 깜깜하지 않게 조정(밤 바깥 [.74,.74,.86,+0,+0,+10], 중간 [.9,.88,.9,+6,+4,+4]). 기본 스탠드가 0권부터 있어 첫날 밤에도 램프 주변이 밝다.
- 방 조명은 프로토타입 JS(`ROOM_TINT`/`ROOM_HALF`/`ROOM_LIT`, `shadeCtx`)가 그린 뒤에 입힘: 색을 곱하고 더한 뒤 PAL32 최근접 색으로 되돌림(팔레트 유지). 켜 둔 스탠드·펜던트는 `art2.json`의 레벨별 `lights`(타원) 범위를 안쪽·중간·바깥 3단으로 밝히고 경계 한 줄만 체크무늬. 창 유리는 제외, 캐릭터는 중간 밝기 아래로 안 내려감.

### 아바타 (v7 확정)
- 28×43px(시트 셀은 28×47, 위 여백 4px), 머리가 키의 약 55%. **비율은 사용자 OK.**
- 얼굴: 둥근 얼굴(볼 높이 최대 폭 유지, 턱은 마지막 3줄만 좁힘). **역삼각형 금지.**
- 눈: 2×3px 검정 + 흰 하이라이트 1점, **모든 스타일에서 고정.** 안경 없음.
- 입: 2px 붉은색(redD). **기본은 무표정**, 웃는 입은 표정 프레임(웃음·놀람)에서만.
- 머리: 어두운 갈색 3단계(woodD 기본 / deep 그림자 / wood 하이라이트). 뒷머리와 앞머리 분리, 앞머리 아래 이마 그림자 1줄(가발 느낌 방지).
- 몸: 목 2줄, 경사진 어깨(으쓱 금지), 흰 양말·검은 운동화. 진한 외곽선.
- 기본 유니폼: 흰 반팔 티 + 남색 바지. 남녀 같은 옷, 차이는 머리 모양만.
- 그리는 순서: 뒷머리 → 후드 → 몸·옷 → 얼굴 → 앞머리 → 눈·볼·입 → 외곽선.
- 헤어 8종(채택): 기본 남성, 기본 여성(단발), 짧은 크롭, 옆가르마, 긴 생머리, 포니테일, 곱슬 파마, 올림 똥머리.
- 옷 8종(채택, 해금 순서대로): 기본 유니폼, 니트, 후드티(**A안 작은 후드**), 줄무늬 티, 사서 조끼, 원피스, 멜빵바지, 트렌치코트.
- 해금 기준(프로토타입 `HAIR_TH`, `OUTFIT_TH`):
  - 머리 순서대로 0, 0, 10, 30, 80, 120, 200, 300권
  - 옷 순서대로 0, 20, 40, 60, 100, 150, 250, 400권
- 숨쉬기 2프레임(몸 1px 상하).

### 자랑 책장과 테마
- 희귀 판단은 시스템이 안 함. 사용자가 고른 책을 표지가 보이는 조명 칸에 꽂고 자랑 문구를 직접 씀(공유 카드에 들어감). 칸 수: Lv.1·2 3칸, Lv.3 8칸, Lv.4 12칸.
- 방 테마는 자랑 책장의 **대표 책** 기준(서재 전체 장르 X): 창밖 풍경, 재질, 소품, 조명색이 따라 바뀜. 동률이면 최근에 꽂은 책 기준. v0는 대표 책 자동만, **테마 직접 고르기는 v1**.

### 데이터
- 서지(v0.7): **카카오 책 검색(주 검색원, `KAKAO_REST_KEY`)** → 쪽수는 서재에 꽂을 때 같은 ISBN으로 구글에서 보충. 시리즈는 카카오 여러 쪽 + 빠진 권 개별 검색(최대 10권) + 영문 병기 무시 비교. **구글 북스 API**(키 `GOOGLE_BOOKS_KEY` 필요. 키 없이는 공용 사용량이 바닥나 429) → 국립중앙도서관 키가 생기면 가장 앞에. 알라딘 Open API는 종료. 구글은 쪽수·표지는 있는 편, 한국 책 장르(categories)는 거의 없어 대부분 '문학'으로 들어가고 사용자가 고친다.
- (참고) 국립중앙도서관 ISBN 서지정보 API(PAGE, BOOK_SIZE, FORM, TITLE_URL, SET_ISBN, ebook_yn 등). 두께 = 쪽수 × 약 0.06mm + 표지(무선 1, 양장 3mm).
- 주의: KDC는 2020-12-31 이후 데이터에서 미제공(SUBJECT에 KDC 대분류 한 자리만 온다는 보고). 부가기호 = 독자대상 1 + 발행형태 1 + 내용분류 3(KDC 강목까지, 끝자리 0). 판단 가능: 문학(8xx), 인문·과학 대분류, 만화(발행형태 7, 단 그림책 섞임·세트/전자책이면 사라짐). **SF·판타지·무협·미스터리는 부가기호로 구분 불가** → 사용자 장르 수정 + 출판사·시리즈 목록 + 책 소개 키워드.
- 코멘트는 앱 내 사용자만(외부 서평 X). 전자책 포함(책등 위아래 하늘색 선).
- 책장 사진 일괄 등록은 v0 필수(1,000권 ≈ 사진 30장).

### 로그인
- 이메일 + 비밀번호 + 초대 코드 6자리. 가입 직후 빈 방 지급.
- 비밀번호: 8자 이상, **소문자·대문자·숫자·기호 각 1개 이상**(Supabase 설정과 앱 규칙 일치), 이메일 아이디 포함 금지, 입력 중 조건 실시간 표시.
- 가입 화면에 **'다른 사이트와 다른 새 비밀번호를 써 달라'** 안내. 서버에서 유출 비밀번호 목록 대조.
